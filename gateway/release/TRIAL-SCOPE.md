# 首个可安装试用版范围

2026-10-30 按用户要求冻结为 **0.3.0-preview.1**。交付Windows x64安装程序、Android访问APK、服务器授权管理命令、最小部署/配对步骤及一个独立SDK示例。保留设备mTLS、精确授权、直连优先/允许时中继、一次性附接、停止回收和不重放业务。

本轮只补上述交付缺口，不扩展传输协议或平台。已有直接相关测试证据复用，只对新增管理命令及最终安装连接流程进行验证。四场景真机和24/72小时稳定性属于后续成熟发布验收，不能将本试用版标为完成生产1.0。后续任务以 [成熟版规格](../docs/mature-release.sdd) 为准。

2026-10-30 实际ECS部署发现带宽排队下的过短心跳和FIN确认预算，以及示例长传输后的闲置控制会话问题。仅修复这些部署阻断项，形成0.3.0-preview.2；保留原安装证据，不扩大后续功能范围。

2026-10-30 用户明确要求统一手机名称、重设计界面并卸载旧版。Android界面更新为0.3.0-preview.3，Windows保持0.3.0-preview.2；旧LinkGate按归属核验退役，新版身份和配对保留，不扩展传输与应用授权范围。
