# LinkGate 手机界面更新

Android **0.3.0-preview.3 / versionCode 4**，名称统一为 **LinkGate**。Windows继续使用0.3.0-preview.2，服务器认证协议与程序保持不变。当前发行目录为仓库根目录 `dist/LinkGate-v0.3.0-preview.3`，包含新APK及保留的Windows安装器、服务器包和校验清单。

## 四个入口

| 页面 | 常用操作 |
| --- | --- |
| 概览 | 查看真实网关状态、启动/停止/取消启动，前往设备或授权 |
| 设备 | 添加电脑的公开配置，查看设备公钥、地址和信任状态，撤销设备 |
| 应用 | 分别审核应用声明与精确访问请求，查看真实包/签名来源及授权范围 |
| 设置 | CSR与证书、服务器配置、操作恢复和连接帮助 |

界面采用浅色背景、深蓝文字、青绿色操作按钮及原生卡片。底部导航固定，内容可滚动；字体按系统设置缩放，宽屏阅读区域限制为680dp。证书指纹、调用方身份及权限范围依然必须由用户核对确认，未知结果依然从原操作恢复。

“网关运行中”只表示网关已启动，不等于某个应用已直连。页面不显示虚构流量或P2P状态；业务路径在应用接入和传输后验证。关闭页面不会停止用户已经启动的前台网关。

## 升级与清理

保持同一包名 `com.nebula.linkgate.agent` 和原开发签名，覆盖安装保留Android Keystore、证书及配对。本次用户已手动打开新版、启动并确认配置正常；Agent未操作手机画面。

用户明确授权后，卸载旧 `com.nebula.linkgate`，移除旧云端 `linkgate-frps.service`、旧程序、旧用户及17400端口规则。恢复档案保存在云端root私有目录。12个旧Windows便携/发行目录已移入回收站，旧桌面入口已更新到当前配置启动器。新版身份/权限库、ReDesk、RustDesk与共享STUN保留。

Windows永久删除命令被自动安全检查拦截，本次改用经完整路径、链接、仓库与进程归属检查后的回收站操作；没有绕过保护进行不可恢复删除。

## 验证边界

使用独立ADB端口的自有Android模拟器，检查四个页面、身份菜单、访问请求空状态、1.3倍字体、1800px及2200px宽屏，验证680dp阅读宽度。最终release APK构建、应用标签/版本、同签名及原生运行时摘要通过；物理手机仅覆盖安装、读取状态及用户手动确认。未重跑传输大套、长稳或四网络测试。具体记录见[冻结证据](../docs/verification-v0.3-ui-retirement.json)。
