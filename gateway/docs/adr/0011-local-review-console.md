# ADR0011：本地交互审核命令行与恢复回执

2026-10-29。新增独立Windows开发命令行，不改变普通应用RPC、SDK或运行服务。它只审核本机声明候选，不签发grant、发布服务或连接业务。宿主可看到调用范围摘要，但当前按SID+EXE路径划分，尚无已核验二进制身份；应用显示名/ID自报，不能当成认证依据。控制台始终显示这一边界。

启动必须指定已存在的registration.db目录，要求交互输入/输出，并先输入OPEN才初始化（可能迁移）数据库。没有批准参数、自动yes、管理HTTP/管道或从重定向输入批准的入口。这个检查只防误用管道自动化，不是同用户恶意进程隔离或不可伪造的人类在场证明。

宿主以有界keyset分页列出引用，选中后显示规范化pending和先前批准的全部内容、两个版本及调用范围。所有不可信文本通过ASCII JSON转义显示，防止ANSI、换行和Unicode方向控制伪造提示。每次决定均需新动作确认短语；取消、EOF或未先展示均不提交。并发变更仍由数据库版本检查拒绝。

确认后先把操作UUID、应用引用、两个版本、决定和未确认状态写入私有回执，再调用Broker。回执使用独占控制台锁、链接拒绝、私有ACL检查、2048字节严格JSON、写穿及Flush(true)后的同目录原子替换。只有已确认回执能被新决定覆盖，未完成或损坏回执不自动重置。文件仅含非秘密引用，不含manifest、身份路径或凭据。

丢回复/确认回执写入失败后，新决定被阻止；recover只查询原操作，匹配引用/修订/版本/决定后确认回执，不自动重放。历史成功不等于当前仍批准。OPERATION_UNKNOWN也不自动重发；经用户核对当前状态后，另行确认abandon仅解除本地等待，不改变Broker状态，也不宣称原操作已回滚。新决定需重新展示并确认。

测试使用脚本终端port及真实私有SQLite/回执文件；实际重定向进程必须在打开状态前拒绝。另在自有样例状态执行了原生PTY批准/撤销自动冒烟，仍不替代真人验收。尚未执行原生交互终端的真人验收、物理磁盘满/断电、跨用户或Android实机测试。本工具不是可信安装器，整体数据库回滚、二进制身份连续性、逐服务/设备授权和业务数据通道继续待实现。
