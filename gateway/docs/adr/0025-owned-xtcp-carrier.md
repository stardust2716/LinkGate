# ADR0025：隔离 XTCP 隧道代次与单流取消

首次公开自动选路验收中，64 MiB 响应在26,591,232字节截断，失败运行号为 `705dc5ccf7f54c96bc783039920637c0`。失败没有被长度或摘要校验掩盖。随后复测通过仍不能解释为长期稳定；本记录保留这次失败。

固定上游的XTCP visitor在打开复用流失败时会关闭当前隧道，未确认失败对应的具体隧道，也没有区别单次取消。旧隧道A的迟到失败可能关闭已经替换的B；并发初始化还可能用重复完成结果替换仍在使用的载体。

仅在显式Agent私有桥模式启用包装层：每次初始化持有独立载体，Open失败只能退役自己观察到且仍为current的载体；调用上下文取消不关闭共用载体。重复初始化完成时关闭新候选并保留已有载体，所有者关闭后拒收迟到结果。普通上游模式不改动。该改动在派生固定源码中应用，不改共享上游目录。

四个确定性屏障测试覆盖旧A失败不关闭新B、重复初始化、单流取消和所有者关闭后的迟到初始化。后端166个顶层测试及vet通过。新运行时的原生SDK验收在故意失效的LAN目标下验证实际XTCP；两条实际直连中取消一条保留另一条。证据见 [公开连接验收](../verification-v0.3-public-connection.json)。

这修复了可复现的载体所有权错误，但没有证明它是首次截断的唯一原因。描述符另用可靠PFD的固定错误状态传播异常；业务仍须校验自身长度/摘要。物理NAT、10万短流及24/72小时运行继续是发布关口。
