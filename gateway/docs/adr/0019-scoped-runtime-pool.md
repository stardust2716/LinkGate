# ADR0019：按完整授权范围复用私有运行时

日期：2026-10-30。状态：Android 已接入；验证见 [运行时池证据](../verification-v0.3-runtime-pool.json)。此决定更新 [ADR0018](0018-android-sdk-server.md) 的每流一个frpc实现。

## 共享范围与取消

Android每条业务流仍持有独立内层设备mTLS、服务器租约和本地grant。只有完整本地authority snapshot相等的流才共享FRP visitor：实际调用主体、应用引用与审核/权限代次、import、对端版本、设备、远端应用/服务、协议/authority和精确grant版本必须相同。当前服务器/设备身份由不可变前台运行代次隔离。不同授权范围不会共用运行时。

一次acquire取得独立lease。关闭其中一个流，只关闭其数据通道并释放自己的lease；其他流继续工作。每个新业务流仍重新取得服务器授权，复用不能使撤权失效。最后一条流关闭后最多保留60秒已使用的空闲session；这不在没有业务请求时自动启动预热。

## 有界所有权

最多16个创建中、运行中或关闭中的runtime，不把正在清理的对象当作空闲容量。创建使用宿主4个线程、零排队执行器；等待者按自己的单调deadline和取消结束。首个等待者离开不会关闭其他等待者使用的创建过程；最后一个离开才作废该创建。迟到资源只能清理，不能再次发布。

factory可在初始化前登记资源；Android先登记session，再在真正启动子进程前登记bridge。初始化失败时仍能观察和处理尚未退出的子进程。资源close失败保留容量，后续维护重试；关闭/创建/授权检查都不持有全池锁。停止先中断业务和作废池，再对自有清理尝试最多3秒，避免故障制造无界后台线程。文件系统或OS无法确认的清理仍不能当作发布就绪证明。

每500毫秒检查已保存的完整本地scope及子进程存活，撤权、重新审核/信任、故障或空闲过期均关闭相关runtime。只删除该runtime生成的私有profile，不扫描、结束其他程序。认证拒绝及标准租约验证失败保留为AUTH_REQUIRED；容量失败为RESOURCE_EXHAUSTED，不误报成远端离线。

## 验证范围

可移植Java池测试使用barrier、受控时钟、晚到结果和故障close，覆盖共同创建、独立取消、超时、scope隔离、空闲过期、换权、阻塞校验时关闭、关闭失败不释放容量、部分初始化失败、错误factory返回对象和单调回退。

独立UID/签名Android消费者通过公开SDK运行64MiB、中继双流及撤权，并确认同scope只有一个自有runtime。消费者主动关闭一条流后，另一条仍ready且阻塞读取保持存活；新open遇到服务器已撤销grant时固定拒绝，业务后端没有新增连接。

这些是资源所有权与小规模业务验收，不代替10万短流、24/72小时、物理ARM64/四网络、XTCP自动优先和网络恢复。Windows运行时池及正式统一连接API继续开发。

## 原生启停竞态

新增停止回收测试时，框架实际报出ForegroundServiceDidNotStartInTimeException。旧入口在startForegroundService尚未完成登记时调用stopService；另外旧实例的销毁或迟到失败回调可能干扰新启动。这个失败作为8a2263c7cf0b40bf8905fed70881519f保留，没有删掉测试或延长前台登记期限。

所有者启动/停止现在通过未导出的服务动作排队，每次启动指令先履行前台登记，再按startId和owner状态执行；停止只终止对应已交付指令。实例所有权和启动代次共同隔离旧onDestroy/迟到失败。测试连续三次立即启停再启动，在真实SDK业务运行中持续观察，末尾额外保持12秒检查最终停止；这仍不是厂商真机后台策略验收。
